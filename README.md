## ⚙️ How to Compile and Run

Make sure you have a modern C++ compiler installed supporting <abbr title="C++20 standard">C++20</abbr> (such as <code>g++</code>, <code>clang++</code>, or MSVC).

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/leetcode-cpp.git
   cd leetcode-cpp
   ```

2. **Compile a specific solution using g++:**
   ```bash
   g++ -std=c++20 -O3 arrays/0001-two-sum.cpp -o solution
   ./solution
   ```
